# Madlib

A Python terminal game inspired by freeCodeCamp.org’s *12 Beginner Python Projects*. Enter a few words and the game fits them into a short story. Each round randomly selects one of three templates.

## Play

From the project directory, run `python main.py` with Python 3. Enter lowercase `y` to start, then answer each prompt. After the story appears, enter `y` to play again or any other response to quit. The game uses Python’s standard library.

## Example round

One template asks for an adjective, two verbs and a famous person. Try **strange**, **dance**, **stretch** and **Ada Lovelace**. The closing sentence becomes:

> Stay hydrated and stretch like you are Ada Lovelace!
